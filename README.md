📄 GOTJOEDFOLIO - Web-Based PDF Suite

An open-source, client-side HTML-based PDF editor inspired by Adobe Acrobat Pro. Perform advanced PDF manipulation—including editing text, converting formats, organizing pages, filling forms, and applying e-signatures—directly within your web browser without uploading files to external servers.

✨ Features

✏️ Create & Edit

Edit PDFs: Modify text, manipulate layout, and insert or adjust images seamlessly.

Create from Scratch: Generate brand new PDFs from Office files (Word, Excel, PowerPoint), images, HTML, or start with a blank canvas.

Combine & Merge: Join multiple PDF documents and files into a single unified document.

Organize Pages: Reorder, rotate, insert, extract, or split pages with interactive visual previews.

🔄 Convert & Export

Export PDFs: Convert PDFs into editable formats including Microsoft Word, Excel, PowerPoint, plain text, or images.

Scan & OCR: Run Optical Character Recognition on scanned PDFs to make text searchable and selectable.

Compress PDF: Optimize and shrink file sizes for easy email sharing and storage.

✍️ Review & Sign

Fill & Sign: Complete fillable PDF forms and add digital handwritten signatures.

Add Comments: Use sticky notes, callouts, drawings, highlighters, and custom stamps for document collaboration.

Prepare Forms: Add customizable form fields, checkboxes, and action buttons.

Request E-signatures: Prepare and streamline agreement signature workflows.

🔒 Protect & Standardize

Protect PDFs: Secure sensitive files with password encryption and custom permissions.

Privacy-First Architecture: Processing runs 100% locally inside your web browser—your documents never leave your machine.
